# CS Course Projects

A few projects I kept from my undergraduate computer science coursework.

## [LA Traffic Collision Pattern Analysis](traffic-collision-analysis/)

A project from my Data Mining coursework using Los Angeles traffic collision data. I used spatial aggregation, DBSCAN, and K-Means to look at patterns in the records, with a small Streamlit interface for exploring the results.

## [Huffman Coding & Decoding](huffman-coding/)

This was an assignment from my Classical Algorithms Design and Implementation course. I implemented the Huffman tree in C, generated the codes in two different ways, and added lossless encoding/decoding and a tree visualization.
