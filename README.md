# CS Course Projects

This repository contains selected undergraduate computer-science coursework projects.

## [Huffman Coding & Decoding](huffman-coding/)

C implementation of Huffman tree construction, two code-generation strategies, encoding/decoding, round-trip tests, and a tree visualization.

## [Traffic Collision Data Mining](data-mining/)

Python coursework project for preprocessing, spatial feature aggregation, clustering, and visualization of traffic-collision data.
